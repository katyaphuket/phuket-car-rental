# Сайт KataCars — phuketrentcar.com

Next.js 16 + Tailwind 4, двуязычный (ru/en). Запуск для проверки: `npm run dev` (http://localhost:3000, в `.claude/launch.json` — конфигурация `dev`).

## Устройство

- `knowledge/` — база знаний компании: машины, доставка, условия аренды, о компании. Описание — `knowledge/README.md`. Код сайта читает JSON отсюда; эту же папку читает `../content-factory`. Данные о компании правим только здесь.
- `src/lib/rentprog.ts` + `src/app/api/cars` — свободные машины и цены из RentProg на нужные даты. Этим API пользуется и content-factory, менять формат ответа осторожно.
- `src/app/api/booking` + `src/lib/amocrm.ts` — заявки с сайта: сделка в amoCRM и письмо через Resend (запасной канал; если в amoCRM не попала, в теме письма будет пометка).
- `src/app/api/amocrm-webhook/[secret]` + `src/lib/lead-notify.ts` — amoCRM сообщает о новой сделке, и если у неё метка «Сайт» или это письмо со старого сайта (katacars.info, попадает в «Неразобранное»), бот пишет в Telegram-группу менеджеров. Адрес зарегистрирован в amoCRM как вебхук на `add_lead` и `update_lead`: о письмах в «Неразобранном» amoCRM сообщает только изменением сделки. Метка «Бот уведомил» защищает от повторных сообщений.
- `src/lib/payroll/` + `src/app/api/payroll/*` — зарплата менеджеров: каждый день в 18:00 по Пхукету (`vercel.json`) бот берёт из amoCRM машину, бюджет (только аренда), даты и поле «Менеджер», сверяет с RentProg по телефону и по машине с датой (брони без сделки, поставленные вчера или раньше, записываются на офис) и присылает всем менеджерам (каждому в личный Telegram) и владелице одинаковые блоки: новые брони с кнопкой «Не согласна», выдачи, сдачи, а для длинных помесячных аренд ещё блок оплат. Споры и непонятные заявки решает только владелица; любую заявку она меняет, прислав боту ссылку или номер сделки. Хранит всё в Google-таблице (служебные вкладки «Заявки», «Начисления», «Люди», «Итоги» и лист на каждый месяц из формул). Сценарии — `npm test`. Без переменных `PAYROLL_*`, `GOOGLE_*`, `CRON_SECRET` бот выключен, сайт работает как обычно.
- `/manager` + `src/lib/offer.ts` + `src/app/o/[token]` — подборка для клиента: менеджер (вход по паролю `MANAGER_PASSWORD`) вводит даты, отмечает свободные машины и получает ссылку `phuketrentcar.com/o/…`. Вся подборка с ценами на момент отправки лежит в самой ссылке и подписана (ключ — `OFFER_SECRET` или, если его нет, производный от `RENTPROG_COMPANY_TOKEN`), базы нет. Подборка устаревает через 3 дня; занятые машины помечаются при открытии. Менеджер может поставить свою цену за день — клиент увидит обычную цену зачёркнутой и плашку «Персональная цена». Кнопка «Хочу эту машину» открывает выбранный менеджером мессенджер с готовым текстом и, если указана сделка, пишет примечание в amoCRM. Экран менеджера — только по-русски.
- `src/lib/amo-offer-link.ts` — поле-ссылка «🚗 Подобрать авто» (тип «ссылка», код `KC_OFFER_LINK`) в карточке сделки amoCRM. Вебхук amoCRM (тот же адрес, что для уведомлений) вписывает в него `phuketrentcar.com/manager?lead=<id>` для новых и изменённых сделок, где ссылки ещё нет («Неразобранное» пропускает). `/manager?lead=<id>` подставляет из сделки даты, имя контакта, район получения, ссылку на сделку и мессенджер последней переписки (метки Wazzup: `com.wazzup24-1` — Telegram, `com.wazzup24.wz` — WhatsApp), чтобы кнопка «Хочу эту машину» вела клиента туда, где он уже пишет. Нет поля в amoCRM — ничего не происходит.
- `src/lib/offer-amo.ts` — что подборка делает в amoCRM, если в ней указана сделка: при создании — примечание со ссылкой и этап «Отправлено предложение»; клиент открыл — примечание «Клиент открыл подборку» (один раз на браузер); клиент нажал «Хочу эту машину» — примечание, машина в поле «Авто», этап «Запросили документы и предоплату» («Ждем бронь/документы» в «Повторных продажах») и сообщение в Telegram-группу менеджеров (оно уходит и без сделки). Сделка двигается только вперёд; «Неразобранное» и закрытые не трогаются. ID этапов — в `PIPELINES`, поменяли воронку в amoCRM — поправить там.
- `src/lib/offer-send.ts` + `src/app/api/offer/send` — кнопка «Отправить клиенту» на `/manager` (если подборка открыта из сделки): текст из окна (шаблоны «С приветствием» / «Без приветствия» / «Коротко» / «Мой шаблон» — свой хранится в браузере менеджера) пишется в поле сделки «Сообщение подборки» (код `KC_OFFER_MESSAGE` или это название) и запускается Salesbot (`OFFER_SALESBOT_ID` в `offer-send.ts` или переменная окружения), который шлёт `{{lead.cf.<ID поля>}}` в последний чат клиента. Без ID бота кнопки нет, остаётся копирование.
- `public/cars/<id>/1.webp, 2.webp…` — фото машин, папка = ID машины в RentProg.
- Переменные окружения (значения не печатать): `RENTPROG_BASE_URL`, `RENTPROG_COMPANY_TOKEN`, `RESEND_API_KEY`, `CONTACT_EMAIL`, `AMOCRM_BASE_URL`, `AMOCRM_ACCESS_TOKEN`, необязательные `AMOCRM_PIPELINE_ID`, `AMOCRM_STATUS_ID`, для уведомлений `AMO_NOTIFY_TELEGRAM_TOKEN`, `AMO_NOTIFY_TELEGRAM_CHAT_ID`, `AMO_WEBHOOK_SECRET`, для зарплаты `PAYROLL_TELEGRAM_TOKEN`, `PAYROLL_TELEGRAM_SECRET`, `PAYROLL_OWNER_CODE`, `PAYROLL_START_DATE`, `PAYROLL_SHEET_ID`, `GOOGLE_SERVICE_ACCOUNT_EMAIL`, `GOOGLE_PRIVATE_KEY`, `CRON_SECRET`, для подборки `MANAGER_PASSWORD` (необязательные `OFFER_SECRET`, `OFFER_BASE_URL`) — в `.env.local` и на хостинге.

## Правила

- Новая машина: описание в `knowledge/cars.json`, перевод — в `knowledge/cars-en.json`, фото — в `public/cars/<id>/`, место в `priority`.
- Тексты на сайте — на двух языках; не оставлять русский текст в английской версии.
- После правок JSON проверить `npm run build` — ошибка в запятой ломает сборку.
- Цены и наличие не хардкодить — они живые из RentProg.
- В планах: Telegram-бот и ИИ-продавец — будут жить в этом проекте (общий код RentProg).
