# База знаний компании

Единое место, где хранятся знания об автопрокате. Отсюда берут данные сайт,
а в будущем — Telegram-бот, ИИ-продавец и фабрика контента (`content-factory`).

Поменяли что-то здесь → после публикации сайта изменение появится на сайте.

## Что где лежит

| Файл | Что внутри | Кто читает |
|---|---|---|
| `cars.json` | Описания машин по ID из RentProg: название, класс, год, кузов, привод, двигатель, фишки. Плюс порядок показа (`priority`) и машины с акцией «Низкая цена» (`lowPriceCarIds`) | сайт |
| `cars-en.json` | Переводы описаний машин на английский. Ключ — русский текст, значение — английский | сайт |
| `delivery.json` | Зоны доставки, цены доставки, минимальный срок аренды по зонам и классам, сезонное правило | сайт |
| `terms.json` | Правила аренды целиком на русском и английском (страница «Условия») | сайт |
| `company.md` | О компании: контакты, преимущества, что бесплатно, как арендовать, отзывы | контент, бот, ИИ |

Свободные машины и цены на конкретные даты здесь не хранятся — они живые и
берутся из RentProg через сайт (`/api/cars`).

## Как править

- Проще всего попросить Claude: «поменяй цену доставки в Патонг на 700».
- Если правите сами: в `.json` файлах меняйте только текст в кавычках и числа,
  не трогая скобки и запятые. Ошибка в запятой сломает сборку сайта.
- Добавили новую машину в `cars.json` с английской версией сайта —
  добавьте перевод её описания в `cars-en.json`, иначе на английском
  останется русский текст.
- В `delivery.json`: `minDaysGroup` у зоны — это ссылка на группу в
  `minDaysGroups` (kata / near / mid / far). Поменяли группу — поменялись все
  её зоны. Сезон `start` / `end` — в формате «месяц-день».
